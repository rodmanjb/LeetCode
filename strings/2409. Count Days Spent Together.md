# 2409. Count Days Spent Together

## Approach
1. Convert each date to a day-of-year number by summing the days in all earlier months and adding the day
2. The overlap starts at the later arrival and ends at the earlier departure
3. Return `leave - arrive + 1` (inclusive), or 0 if they never overlap

## Complexity
Time: O(1), since the months list is a fixed 12 entries  
Aux Space: O(1)

## Solution
```python
class Solution:
    def countDaysTogether(self, arriveAlice: str, leaveAlice: str, arriveBob: str, leaveBob: str) -> int:
        months = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

        monthAA, dayAA = arriveAlice.split("-")
        AA = sum(months[:int(monthAA) - 1]) + int(dayAA)

        monthAL, dayAL = leaveAlice.split("-")
        AL = sum(months[:int(monthAL) - 1]) + int(dayAL)

        monthBA, dayBA = arriveBob.split("-")
        BA = sum(months[:int(monthBA) - 1]) + int(dayBA)

        monthBL, dayBL = leaveBob.split("-")
        BL = sum(months[:int(monthBL) - 1]) + int(dayBL)

        arrive = max(AA, BA)
        leave = min(AL, BL)
        return max(0, leave - arrive + 1)
```
