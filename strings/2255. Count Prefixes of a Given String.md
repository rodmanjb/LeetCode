# 2255. Count Prefixes of a Given String

## Approach
1. For each word, slice the first `len(word)` characters of `s`
2. If the word matches that slice, it's a prefix, so add 1 to the count
3. If the word is longer than `s`, the slice is shorter than the word and can't match

## Complexity
Time: O(n * m), where n is the number of words and m is the max word length  
Aux Space: O(m) for the slice

## Solution
```python
class Solution:
    def countPrefixes(self, words: list[str], s: str) -> int:
        count = 0
        for i in words:
            length = len(i)
            temp = s[:length]
            if i in temp:
                count += 1
        return count
```
