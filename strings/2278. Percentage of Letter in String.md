# 2278. Percentage of Letter in String

## Approach
1. Loop through `s` and count how many characters match `letter`
2. Divide by `len(s)`, multiply by 100, and use `int()` to round down

## Complexity
Time: O(n)  
Aux Space: O(1)

## Solution
```python
class Solution:
    def percentageLetter(self, s: str, letter: str) -> int:
        count = 0
        for i in s:
            if i == letter:
                count += 1

        return int((count / len(s)) * 100)
```
