# 1805. Number of Different Integers in a String

## Approach
1. Loop through `word` with an extra letter added to the end, so the last run of digits always gets flushed
2. While the character is a digit, push it onto `stack`
3. On a non-digit, if the stack has digits, join them into a number and convert with `str(int(...))`, which strips leading zeros (`"001"` becomes `"1"`)
4. Clear the stack and add the number to `numbers` if it isn't already there
5. Return how many different numbers were found

## Complexity
Time: O(n * k), where k is the number of unique integers, since `not in` on a list is a linear scan  
Aux Space: O(n)

## Solution
```python
class Solution:
    def numDifferentIntegers(self, word: str) -> int:
        stack = []
        numbers = []
        nums = "0123456789"
        for i in word + "a":
            if i in nums:
                stack.append(i)
            else:
                temp = ""
                if len(stack) > 0:
                    temp = "".join(stack)
                    temp = str(int(temp))
                    stack.clear()
                    if temp not in numbers:
                        numbers.append(temp)
        return len(numbers)
```
