# 3216. Lexicographically Smallest String After a Swap

## Approach
1. Go through adjacent pairs from left to right
2. A swap is allowed only if both digits have the same parity (both even or both odd)
3. The first pair where the left digit is bigger than the right digit and the parities match is the best swap, since it makes the earliest position smaller
4. Swap that pair and return straight away
5. If no pair qualifies, `s` is already the smallest, so return it unchanged

## Complexity
Time: O(n)  
Aux Space: O(n) for the list conversion when swapping

## Solution
```python
class Solution:
    def getSmallestString(self, s: str) -> str:
        for i in range(0, len(s) - 1):
            if int(s[i]) % 2 == 0:
                if int(s[i+1]) % 2 == 0 and int(s[i]) > int(s[i+1]):
                    s = list(s)
                    s[i], s[i+1] = s[i+1], s[i]
                    s = "".join(s)
                    return s
            else:
                if int(s[i+1]) % 2 != 0 and int(s[i]) > int(s[i+1]):
                    s = list(s)
                    s[i], s[i+1] = s[i+1], s[i]
                    s = "".join(s)
                    return s
        return s
```
