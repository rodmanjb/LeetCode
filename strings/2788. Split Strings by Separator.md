# 2788. Split Strings by Separator

## Approach
1. For each word, build up a string `curr` one character at a time
2. When a character matches `separator`, push `curr` to the output if it isn't empty, then reset it
3. After the word ends, push whatever is left in `curr` (if not empty)
4. Empty pieces are skipped, as the problem requires

## Complexity
Time: O(n), where n is the total number of characters across all words  
Aux Space: O(n) for the output

## Solution
```python
class Solution:
    def splitWordsBySeparator(self, words: List[str], separator: str) -> List[str]:
        output = []
        for word in words:
            curr = ""
            for i in word:
                if i == separator:
                    if len(curr) > 0:
                        output.append(curr)
                    curr = ""
                    continue
                else:
                    curr += i
            if len(curr) > 0:
                output.append(curr)
        return output
```
