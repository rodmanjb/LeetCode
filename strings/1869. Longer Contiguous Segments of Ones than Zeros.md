# 1869. Longer Contiguous Segments of Ones than Zeros

## Approach
1. Keep a running streak for 1s (`cur1`) and for 0s (`cur0`), plus the longest seen so far for each (`max1`, `max0`)
2. On a `"1"`, reset `cur0` to 0, grow `cur1`, and update `max1` if it's a new best
3. On a `"0"`, do the same with the roles swapped
4. Return `max1 > max0`

## Complexity
Time: O(n)  
Aux Space: O(1)

## Solution
```python
class Solution:
    def checkZeroOnes(self, s: str) -> bool:
        max1 = 0
        max0 = 0
        cur0, cur1 = 0, 0

        for i in s:
            if i == "1":
                cur0 = 0
                cur1 += 1
                if cur1 > max1:
                    max1 = cur1
            else:
                cur1 = 0
                cur0 += 1
                if cur0 > max0:
                    max0 = cur0
        return max1 > max0
```
