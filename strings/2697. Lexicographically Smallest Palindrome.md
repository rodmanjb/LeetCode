# 2697. Lexicographically Smallest Palindrome

## Approach
1. Turn `s` into a list so characters can be changed, and set two pointers at the start and end
2. Compare `s[left]` and `s[right]`. If they differ, set both positions in the output to the smaller of the two
3. Move the pointers inward until they meet
4. Join the list back into a string

## Complexity
Time: O(n)  
Aux Space: O(n) for the output list

## Solution
```python
class Solution:
    def makeSmallestPalindrome(self, s: str) -> str:
        output = list(s)
        left = 0
        right = len(s) - 1

        while left < right:
            if s[left] != s[right]:
                if s[left] < s[right]:
                    curr = s[left]
                else:
                    curr = s[right]
                output[left] = curr
                output[right] = curr

            left += 1
            right -= 1

        return "".join(output)
```
