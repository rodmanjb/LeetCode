# 1790. Check if One String Swap Can Make Strings Equal

## Approach
1. If the strings are already equal, return `True` (no swap needed)
2. Collect the indices where `s1` and `s2` differ
3. Exactly 2 differences is the only other case that can work, and only if swapping fixes both: `s1[i] == s2[j]` and `s1[j] == s2[i]`
4. Anything else (1 difference, or 3+) is `False`

## Complexity
Time: O(n)  
Aux Space: O(1), since `diff` never holds more than a few indices before we bail out in practice (worst case O(n) if you let it fill up)

## Solution
```python
class Solution:
    def areAlmostEqual(self, s1: str, s2: str) -> bool:
        if s1 == s2:
            return True
        diff = []
        for i in range(len(s1)):
            if s1[i] != s2[i]:
                diff.append(i)
        if len(diff) == 0:
            return True
        if len(diff) == 2:
            i, j = diff
            return s1[i] == s2[j] and s1[j] == s2[i]
        return False
```
