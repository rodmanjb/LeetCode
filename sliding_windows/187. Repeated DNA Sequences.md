# 187. Repeated DNA Sequences

## What I learned
* A sliding window of fixed size 10 means looping `range(len(s) - 9)` and slicing `s[i:i+10]` so the window never runs off the end
* A set gives O(1) average membership checks, so "have I seen this before?" doesn't need a nested loop
* Using two sets splits the jobs: `seen` tracks every window so far, `end` collects the ones that repeat
* Making `end` a set means a sequence that shows up 3+ times is only added once, so there are no duplicates in the result

## Approach
1. Slide a window of length 10 across the string
2. If the window is already in `seen`, add it to `end`
3. Otherwise add it to `seen`
4. Return `end` as a list

## Complexity
Time: O(n), where each slice and hash costs O(10), which is constant  
Aux Space: O(n) for the two sets

## Solution
```python
class Solution:
    def findRepeatedDnaSequences(self, s: str) -> list[str]:
        seen = set()
        end = set()

        for i in range(len(s) - 9):
            curr = s[i:i+10]
            if curr in seen:
                end.add(curr)
            else:
                seen.add(curr)

        return list(end)
```
