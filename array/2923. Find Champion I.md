# 2923. Find Champion I

## Approach
1. For each team (row), count how many 1s it has, which is how many teams it beats, and store that in `power`
2. The champion beats every other team, so it has the highest count
3. Scan `power` for the index with the largest value and return it

## Complexity
Time: O(n²), since every cell in the grid is checked once  
Aux Space: O(n) for the `power` array

## Solution
```java
class Solution {
    public int findChampion(int[][] grid) {
        int n = grid.length;
        int[] power = new int[n];
        for (int i = 0; i < n; i++) {
            int count = 0;
            int m = grid[i].length;
            for (int x = 0; x < m; x++) {
                if (grid[i][x] == 1) {
                    count++;
                }
            }
            power[i] = count;
        }
        int maxIndex = 0;
        for (int i = 1; i < n; i++) {
            if (power[i] > power[maxIndex]) {
                maxIndex = i;
            }
        }
        return maxIndex;
    }
}
```
