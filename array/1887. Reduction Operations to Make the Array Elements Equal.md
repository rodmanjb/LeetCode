# 1887. Reduction Operations to Make the Array Elements Equal

## Approach
1. Sort the array ascending
2. Walk through from index 1. When `nums[i] != nums[i-1]`, we've hit a new distinct value, so `smaller += 1`
3. Add `smaller` to `count` for every element (that's how many steps it takes to reduce down to the minimum)

## Complexity
Time: O(n log n) for the sort, O(n) for the pass  
Aux Space: O(n) for Python's Timsort (O(1) for the loop itself)

## Solution
```python
class Solution:
    def reductionOperations(self, nums: list[int]) -> int:
        nums.sort()
        count = 0
        smaller = 0
        for i in range(1, len(nums)):
            if nums[i] != nums[i-1]:
                smaller += 1
            count += smaller
        return count
```
