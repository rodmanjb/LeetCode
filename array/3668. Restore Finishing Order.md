# 3668. Restore Finishing Order

## Approach
1. Loop through `order`, which lists everyone in the order they finished
2. If that person is one of the `friends`, add them to the result
3. The result ends up as just the friends, in finishing order

## Complexity
Time: O(n * m), where n = `len(order)` and m = `len(friends)`, since `in` on a list is a linear scan  
Aux Space: O(m) for the result

## Solution
```python
class Solution(object):
    def recoverOrder(self, order, friends):
        """
        :type order: List[int]
        :type friends: List[int]
        :rtype: List[int]
        """
        result = []
        for i in order:
            if i in friends:
                ind = friends.index(i)
                result.append(friends[ind])

        return result
```
