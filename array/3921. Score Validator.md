# 3921. Score Validator

## Approach
1. Keep a running `score` and a wicket `counter`
2. `"WD"` (wide) and `"NB"` (no ball) each add 1 run
3. `"W"` is a wicket, so add 1 to `counter`. At 10 wickets the innings is over, so return straight away and ignore any later events
4. Any other event is a number of runs, so add `int(i)` to the score
5. If the loop finishes, return `[score, counter]`

## Complexity
Time: O(n)  
Aux Space: O(1)

## Solution
```python
class Solution:
    def scoreValidator(self, events: list[str]) -> list[int]:
        score, counter = 0, 0
        for i in events:
            if i == "WD" or i == "NB":
                score += 1
            elif i == "W":
                counter += 1
                if counter == 10:
                    return [score, counter]
            else:
                score += int(i)
        return [score, counter]
```
