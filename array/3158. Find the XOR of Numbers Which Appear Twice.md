# 3158. Find the XOR of Numbers Which Appear Twice

## Approach
1. Loop through `nums`, keeping a `seen` list of numbers met so far
2. If a number is already in `seen`, it's the second time we've hit it, so add it to `seentwice`
3. XOR everything in `seentwice` together with `reduce(xor, seentwice, 0)`
4. If nothing appears twice, the `0` initial value makes it return `0`

## Complexity
Time: O(n²), since `in` on a list is a linear scan  
Aux Space: O(n) for the two lists

## Solution
```python
from functools import reduce
from operator import xor

class Solution:
    def duplicateNumbersXOR(self, nums: List[int]) -> int:
        seen, seentwice = [], []
        for i in nums:
            if i in seen:
                seentwice.append(i)
            else:
                seen.append(i)
        return reduce(xor, seentwice, 0)
```
