# 2148. Count Elements With Strictly Smaller and Greater Elements

## Approach
1. Sort a copy of the array so the min is at index 0 and the max is at index -1
2. An element has both a strictly smaller and a strictly greater element exactly when it's greater than the min and less than the max
3. Count those elements (the strict checks skip duplicates of the min and max)

## Complexity
Time: O(n log n) for the sort  
Aux Space: O(n) for the sorted copy

## Solution
```python
class Solution:
    def countElements(self, nums: list[int]) -> int:
        numsort = sorted(nums)
        count = 0
        for i in range(1, len(numsort) - 1):
            if numsort[0] < numsort[i]:
                if numsort[i] < numsort[-1]:
                    count += 1
        return count
```
