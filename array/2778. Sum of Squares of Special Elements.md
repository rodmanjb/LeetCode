# 2778. Sum of Squares of Special Elements

## Approach
1. The array is 1-indexed in the problem, so index `i` in the loop maps to `nums[i-1]`
2. An element is special if `i` divides `n` evenly (`n % i == 0`)
3. Add the square of each special element to the total

## Complexity
Time: O(n)  
Aux Space: O(1)

## Solution
```python
class Solution:
    def sumOfSquares(self, nums: List[int]) -> int:
        n = len(nums)
        total = 0
        for i in range(1, n+1):
            if n % i == 0:
                total += (nums[i-1]*nums[i-1])
        return total
```
