# 3010. Divide an Array Into Subarrays With Minimum Cost I

## Approach
1. The first subarray must start at index 0, so `nums[0]` is always part of the cost
2. The other two subarrays can start at any two later indices, so we want the two smallest values from `nums[1:]`
3. Track those two minimums (`num2` smallest, `num3` second smallest) in a single pass, starting both at 51 since values are at most 50
4. Return `nums[0] + num2 + num3`

## Complexity
Time: O(n)  
Aux Space: O(1)

## Solution
```python
class Solution:
    def minimumCost(self, nums: List[int]) -> int:
        cost = nums[0]
        num2, num3 = 51, 51
        for i in range(1,len(nums)):
            if nums[i] < num2:
                num3 = num2
                num2 = nums[i]
            elif nums[i] < num3:
                num3 = nums[i]
        return cost + num2 + num3
```
