# 3151. Special Array I

## Approach
1. Track whether the previous number was even with a boolean `var`, starting from `nums[0]`
2. For each next number, check its parity. If it matches the previous parity, return `False`
3. Otherwise flip `var` to the new parity and continue
4. If we get through the whole array without a match, return `True`

## Complexity
Time: O(n)  
Aux Space: O(1)

## Solution
```python
class Solution:
    def isArraySpecial(self, nums: List[int]) -> bool:
        if (nums[0] % 2 == 0):
            var = True
        else:
            var = False
        for i in range(1, len(nums)):
            if (nums[i] % 2 == 0):
                if var == True:
                    return False
                else:
                    var = True
                    continue
            else:
                if var == False:
                    return False
                else:
                    var = False
                    continue
        return True
```
