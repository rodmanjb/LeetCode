# 2363. Merge Similar Items

## Approach
1. Loop through `items1` and `items2`, adding each weight into a hashmap under its value
2. Loop through the sorted keys and build `[value, total_weight]` pairs for the result

## Complexity
Time: O(n log n), where n is the number of unique values (the sort dominates)  
Aux Space: O(n) for the hashmap and result

## Solution
```python
class Solution:
    def mergeSimilarItems(self, items1: list[list[int]], items2: list[list[int]]) -> list[list[int]]:
        hashmap = {}
        ret = []
        for i in items1:
            if i[0] in hashmap:
                hashmap[i[0]] += i[1]
            else:
                hashmap[i[0]] = i[1]
        for i in items2:
            if i[0] in hashmap:
                hashmap[i[0]] += i[1]
            else:
                hashmap[i[0]] = i[1]
        for j in sorted(hashmap):
            ret.append([j, hashmap[j]])
        return ret
```
