# 2974. Minimum Number Game

## Approach
1. Sort `nums` so the smallest values are at the front
2. Take the two smallest, `x` and `y`. Alice removes `x`, then Bob removes `y`, but Bob appends first, so the result gets `y` then `x`
3. Delete both from the front and repeat until `nums` is empty
4. Return `res`

## Complexity
Time: O(n²), since each `del nums[0]` shifts the whole list (the sort itself is O(n log n))  
Aux Space: O(n) for the sorted copy and result

## Solution
```python
class Solution:
    def numberGame(self, nums: List[int]) -> List[int]:
        res = []
        nums = sorted(nums)
        while len(nums) != 0:
            x, y = nums[0], nums[1]
            del nums[0]
            del nums[0]
            res.append(y), res.append(x)
        return res
```
