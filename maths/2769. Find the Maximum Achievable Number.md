# 2769. Find the Maximum Achievable Number

## Approach
1. Each operation changes `x` and `num` by 1 each, so the gap between them closes by at most 2 per operation
2. Move `x` down and `num` up every time, so after `t` operations they meet at `num + t`
3. That means the largest `x` that can reach `num` is `num + 2 * t`

## Complexity
Time: O(1)  
Aux Space: O(1)

## Solution
```python
class Solution:
    def theMaximumAchievableX(self, num: int, t: int) -> int:
        num += (2*t)
        return num
```
