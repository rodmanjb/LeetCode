# 762. Prime Number of Set Bits in Binary Representation

## Approach
1. For each number in `[left, right]`, count its set bits using `bin(i)`
2. Check whether that count is prime by trial division up to its square root
3. Increment the total when the count is prime

## Complexity
Time: O(n * log(right)), where n = right - left + 1 (bit counting dominates, the prime check is on a number ≤ ~20 so it's constant)  
Aux Space: O(log(right)) for the binary string

## Solution
```python
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:
        def isPrime(target):
            if target <= 1:
                return False
            for i in range(2, int(target**0.5) + 1):
                if target % i == 0:
                    return False
            return True

        count = 0
        for i in range(left, right + 1):
            binaryrep = bin(i)
            counter = 0
            for x in str(binaryrep):
                if x == "1":
                    counter += 1
            if isPrime(counter):
                count += 1
        return count
```
