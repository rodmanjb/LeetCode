# 2917. Find the K-or of an Array

## Approach
1. Check each bit position `i` from 0 to 30 (values are below 2^31)
2. For each position, count how many numbers in `nums` have that bit set using `num & (1 << i)`
3. If at least `k` numbers have the bit set, turn it on in the output with `output |= (1 << i)`
4. Return the output

## Complexity
Time: O(31 * n), which is O(n)  
Aux Space: O(1)

## Solution
```python
class Solution:
    def findKOr(self, nums: List[int], k: int) -> int:
        output = 0
        for i in range(0, 31):
            curr = 0
            for num in nums:
                if num & (1 << i):
                    curr += 1
            if curr >= k:
                output |= (1 << i)
        return output
```
