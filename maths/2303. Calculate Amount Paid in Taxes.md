# 2303. Calculate Amount Paid in Taxes

## Approach
1. Go through the brackets in order, tracking the previous bracket's upper limit as `prev`
2. The size of each bracket is `upper - prev`
3. If the remaining income covers the whole bracket, tax the full size at that percentage and subtract it from `income`
4. Otherwise tax only the remaining income at that percentage and set `income` to 0
5. Stop when the income runs out or the brackets do

## Complexity
Time: O(n), where n is the number of brackets  
Aux Space: O(1)

## Solution
```python
class Solution:
    def calculateTax(self, brackets: list[list[int]], income: int) -> float:
        tax = 0
        i = 0
        prev = 0
        while income > 0 and i < len(brackets):
            upper = brackets[i][0]
            perc = brackets[i][1]
            size = upper - prev

            if income >= size:
                tax += size * (perc / 100)
                income -= size
            else:
                tax += income * (perc / 100)
                income = 0

            prev = upper
            i += 1
        return tax
```
