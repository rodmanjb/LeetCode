# 3894. Traffic Signal

## Approach
1. Check `timer` against each case in order
2. `0` gives `"Green"` and `30` gives `"Orange"`
3. Anything above 30 up to and including 90 gives `"Red"`
4. Everything else (negative, between 1 and 29, or above 90) is `"Invalid"`

## Complexity
Time: O(1)  
Aux Space: O(1)

## Solution
```python
class Solution:
    def trafficSignal(self, timer: int) -> str:
        if timer == 0:
            return "Green"
        if timer == 30:
            return "Orange"
        if 30 < timer <= 90:
            return "Red"
        return "Invalid"
```
