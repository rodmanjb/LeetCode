# 1925. Count Square Sum Triples

## Approach
1. Treat `i` as the hypotenuse `c` and loop over every `i` from 1 to `n`
2. For each `i`, try all pairs `x` and `y` below `i`
3. If `x*x + y*y == i*i`, count it. Both `(3, 4, 5)` and `(4, 3, 5)` count, since the problem treats order as different

## Complexity
Time: O(n³)  
Aux Space: O(1)

## Solution
```python
class Solution:
    def countTriples(self, n: int) -> int:
        count = 0
        for i in range(1, n+1):
            for x in range(1, i):
                for y in range(1, i):
                    if x*x + y*y == i*i:
                        count += 1

        return count
```
