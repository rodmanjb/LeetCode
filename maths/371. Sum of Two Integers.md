# 371. Sum of Two Integers

## Approach
1. XOR (`a ^ b`) adds the bits without the carry
2. AND shifted left (`(a & b) << 1`) gives the carry
3. Repeat with `a = a ^ b` and `b = carry` until there is no carry left
4. Python ints are unbounded, so mask to 32 bits to stop the loop on negatives. If the loop ended with a leftover `b`, mask the answer back to 32 bits

## Complexity
Time: O(1), at most 32 iterations  
Aux Space: O(1)

## Solution
```python
class Solution:
    def getSum(self, a: int, b: int) -> int:
        mask = 0xffffffff
        while (b & mask) != 0:
            carry = (a & b) << 1
            a = a ^ b
            b = carry

        return a & mask if b > 0 else a
```
